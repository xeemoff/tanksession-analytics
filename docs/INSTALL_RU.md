# Установка и обновление TankSession Analytics

Нужен Windows и установленный «Мир танков». Для **готового Windows-архива** не требуется устанавливать Python, Node.js или средства разработки. PowerShell 5.1 входит в Windows. Версия клиента и статус испытаний указаны в `manifest.json` и `RELEASE_NOTES_RU.md` внутри архива.

Версия с суффиксом `-rc` — кандидат для испытаний. Указанная для кандидата версия клиента означает целевую версию проверки; она не подтверждает, что все функции уже испытаны в игре. Браузерное демо и игровые испытания имеют отдельные результаты.

## Быстрая установка готового Windows-архива

1. Закрой игру и полностью распакуй `TankSession_Analytics_<версия>_Windows.zip` в обычную папку. Запускать файлы прямо из ZIP не нужно. Сохрани все файлы архива рядом: установщик читает пакет, `manifest.json` и контрольную сумму.
2. Запусти **`manager.cmd`**. Нажми «Найти игру» или выбери папку, например `C:\Games\Tanki`, проверь версию клиента и нажми «Установить / обновить».

Графический менеджер появился в 2.0. Автопоиск проверяет обычные папки на локальных дисках и записи установленных игр в Windows. Если игра стоит в другом месте, укажи её через «Выбрать папку». При нескольких найденных установках выбери нужную. Версия клиента выбирается только из целевых версий пакета; установщик проверяет наличие соответствующей папки. Он не объявляет оставшуюся на диске старую папку актуальным клиентом.

Прежний **`install.cmd`** сохранён: он задаёт вопросы о пути и версии в консоли. Ручное копирование `.mtmod` также доступно.

Установщик проверяет SHA-256, имя и состав `.mtmod`, версию клиента и отсутствие работающего процесса игры. Он не выбирает «самую большую» папку версии: после обновления клиента в `mods` могут оставаться старые каталоги. Указанная версия должна присутствовать и в установке игры, и в списке целевых версий пакета.

Перед установкой 2.0 сохраняется проверенный ZIP-снимок имеющихся истории и настроек в `mods/tanksession_data_backups/`. Прежние пакеты **только TankSession** сохраняются в `mods/tanksession_backups/`, с перечнем файлов и SHA-256. Затем установщик заменяет пакеты в выбранной папке версии. Если замена не удалась, он пытается восстановить прежние файлы и сообщает путь к копии. Во время установки содержимое пользовательских данных и других модов не меняется.

Установщик не требует администратора. Если папка игры недоступна для записи, исправь права обычным способом или выполни ручную установку. `install.cmd` задаёт политику выполнения PowerShell только для своего процесса; системные настройки PowerShell не меняются. Не нужно снимать ограничения на выполнение скриптов глобально.

### Только проверка без установки

Открой PowerShell в распакованной папке:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-TankSession.ps1 -GamePath "C:\Games\Tanki" -ClientVersion "1.46.0.0" -CheckOnly
```

Проверка не создаёт резервные копии и не меняет файлы игры.

## Если обновляешь уже работающий мод

Папка `mods/configs/tanksession_analytics/` должна остаться на месте. В ней находятся накопленные данные, в том числе `battles.jsonl` и `battles.jsonl.pending.jsonl`. При обновлении меняется пакет `.mtmod`; прежние переключатели интерфейса и восстановления сохраняются.

Для переноса на другой диск используй кнопку «Экспорт / резервная копия…» и сохрани архив вне папки игры. Автоматическая копия рядом с игрой защищает от ошибки обновления мода, но не от удаления самой папки игры или отказа диска.

## Резервная копия и перенос истории

Закрой игру и браузерный просмотр истории перед экспортом или импортом. **Экспорт сохраняет целиком локальную историю всех аккаунтов**, `settings.json`, прежний `goals.json` и профили `profiles/<64hex>.json`. Начиная с RC2 включены также их точные копии `.json.bak`, `.json.rollback` и `.json.bak.rollback`: после прерванного сохранения файл восстановления может быть единственным действующим источником настроек. Журнал ожиданий, логи, CSV, временные `.tmp` и чужие файлы в архив не входят. Ожидания не переносятся между установками, чтобы не запускать запросы к кэшу другой сессии.

Каждый файл указан в `history-manifest.json` с размером и SHA-256. Архив проверяется после записи. Максимум — 512 файлов, 128 МиБ на файл и 256 МиБ суммарно. Превышение лимита даёт ошибку до замены данных; для больших журналов доступно отдельное обслуживание `tools/maintain_data.py` при закрытой игре.

**Импорт восстанавливает снимок, а не объединяет два журнала.** Перед заменой создаётся проверенная копия текущих данных. Заменяются только перечисленные файлы; прочие файлы и профили остаются. При ошибке применения менеджер восстанавливает заменённые файлы, а при неудаче отката сохраняет материал для ручного восстановления и показывает его путь. Архивы с лишними путями, дубликатами, неверными размерами или хешами отклоняются.

Если снимок содержит только `.rollback`, а соответствующий основной файл уже существует и отсутствует в архиве, импорт останавливается до изменения данных. Такой снимок сначала восстанавливается в отдельную копию установки без конфликтующего основного файла; Workspace при чтении проверит файл восстановления и вернёт его на основное место. Полный снимок, содержащий обе версии, разрешён. Это исключает сообщение об успешном восстановлении настроек, которые фактически остались бы прежними.

Архив содержит ID из журнала и личные настройки; его хеш не шифрует содержимое. Для публичного обмена статистикой используй CSV из интерфейса: в нём нет ID аккаунта и боя.

## Проверка обновлений

В менеджере есть кнопка «Проверить обновления» и переключатель предварительных версий. Запрос выполняется только по нажатию, к API выпусков этого репозитория на GitHub. История и настройки в запрос не передаются. Показывается более новая версия с опубликованным Windows-архивом; скачать её и сверить целевой клиент можно через «Страница выпуска». Менеджер не скачивает и не запускает новые файлы автоматически. При недоступном GitHub установка, копии и работа мода остаются офлайн.

## Первое включение окна в ангаре

Сбор собственных результатов и окно Gameface — отдельные компоненты. Загрузчик **OpenWG Gameface** в поставку TankSession не включён и автоматически не скачивается.

1. Установи подходящий `.mtmod` OpenWG Gameface для «Мира танков» по [инструкции автора](https://gitlab.com/openwg/wot.gameface/-/releases). Не используй вариант для Wargaming World of Tanks.
2. При закрытой игре создай или дополни `mods/configs/tanksession_analytics/settings.json`, сохранив остальные настройки:

```json
{
  "experimental_gameface_ui": true,
  "experimental_cache_recovery": false
}
```

Если файл уже есть, меняй только нужное поле, не заменяй весь файл примером. По умолчанию дополнительный UI и экспериментальное восстановление выключены. Настройки читаются при запуске. Внешний загрузчик при первой регистрации ресурсов может потребовать перезапуск игры — следуй его инструкции.

После загрузки ангара нажми **F8**. В интерфейсе видны только сохранённые бои текущего подтверждённого аккаунта. Пустая история после первой установки ожидаема: мод не импортирует автоматически все прежние бои аккаунта.

## Ручная установка

При закрытой игре проверь SHA-256 файла против строки в `.sha256`, сохрани старые `ru.tanksession.analytics_*.mtmod` вне папки активных модов и скопируй новый пакет в `mods/<точная версия клиента>/`. Оставь одну версию TankSession. Не перемещай другие `.mtmod` и папку с историей.

```powershell
(Get-FileHash ".\ru.tanksession.analytics_2.0.0-rc2.mtmod" -Algorithm SHA256).Hash
```

Имя файла в команде замени на имя из своего архива. Совпадение хеша подтверждает целостность скачанного пакета относительно опубликованной контрольной суммы; оно не является подписью издателя и не заменяет игровой тест.

## Откат

В менеджере выбери копию пакета и нажми «Вернуть пакет». Сначала проверяются её хеши и версия клиента; заменяемый пакет тоже сохраняется. Список включает копии с манифестом, созданные менеджером 2.0.

Для прежних копий без манифеста доступен ручной способ: закрой игру, убери текущий пакет TankSession из активной папки и верни прежний `.mtmod` в `mods/<та же версия клиента>/`. Не смешивай два пакета TankSession. История и настройки остаются на месте. При неудачном откате менеджер показывает каталог копии.

## Отключение и удаление

Чтобы отключить окно, при закрытой игре выставь `experimental_gameface_ui` в `false` и перезапусти клиент. Для удаления нажми «Удалить мод» в менеджере: пакеты TankSession сохранятся в копию и будут удалены только из выбранной версии клиента. История, настройки и остальные моды сохраняются. Ручной вариант — удалить только `ru.tanksession.analytics_<версия>.mtmod` из активной папки. OpenWG может использоваться другими модами; его удаление выполняется отдельно по инструкции автора.

После обновления клиента используй пакет, предназначенный для новой версии, и повтори проверку. Перенос старого `.mtmod` в новую папку сам по себе не подтверждает совместимость.

## Об ошибках

При ошибке установки сохрани её текст и версию пакета. Не отправляй весь `python.log`, журналы боёв и `manifest.json` из неизвестных источников в публичные обсуждения. Для игровых проблем используй обезличенную диагностику проекта и список сценариев в [протоколе испытаний](https://github.com/xeemoff/tanksession-analytics/blob/main/docs/CLIENT_VALIDATION_RU.md).

TankSession Analytics — самостоятельный неофициальный проект. Он не опубликован и не одобрен Lesta Games.
