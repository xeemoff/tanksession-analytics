# Установка и обновление TankSession Analytics

Нужен Windows и установленный «Мир танков». Для **готового Windows-архива** не требуется устанавливать Python, Node.js или средства разработки. PowerShell 5.1 входит в Windows. Версия клиента и статус испытаний указаны в `manifest.json` и `RELEASE_NOTES_RU.md` внутри архива.

Версия с суффиксом `-rc` — кандидат для испытаний. Указанная для кандидата версия клиента означает целевую версию проверки; она не подтверждает, что все функции уже испытаны в игре. Браузерное демо и игровые испытания имеют отдельные результаты.

## Быстрая установка готового Windows-архива

1. Закрой игру и полностью распакуй `TankSession_Analytics_<версия>_Windows.zip` в обычную папку. Запускать файлы прямо из ZIP не нужно. Сохрани все файлы архива рядом: установщик читает пакет, `manifest.json` и контрольную сумму.
2. Запусти `install.cmd`. Введи полный путь к игре, например `C:\Games\Tanki`, затем точную версию клиента — имя актуальной папки внутри `mods`, например `1.46.0.0`.

Установщик проверяет SHA-256, имя и состав `.mtmod`, версию клиента и отсутствие работающего процесса игры. Он не выбирает «самую большую» папку версии: после обновления клиента в `mods` могут оставаться старые каталоги. Указанная версия должна присутствовать и в установке игры, и в списке целевых версий пакета.

Сначала установщик создаёт и проверяет резервные копии прежних пакетов **только TankSession** в `mods/tanksession_backups/`. После проверки копии нового файла он заменяет пакеты в выбранной папке версии. Если замена не удалась, установщик пытается восстановить прежние файлы и сообщает путь к резервной копии. Он не меняет другие моды, `mods/configs/tanksession_analytics/`, историю боёв и настройки.

Установщик не требует администратора. Если папка игры недоступна для записи, исправь права обычным способом или выполни ручную установку. `install.cmd` задаёт политику выполнения PowerShell только для своего процесса; системные настройки PowerShell не меняются. Не нужно снимать ограничения на выполнение скриптов глобально.

### Только проверка без установки

Открой PowerShell в распакованной папке:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-TankSession.ps1 -GamePath "C:\Games\Tanki" -ClientVersion "1.46.0.0" -CheckOnly
```

Проверка не создаёт резервные копии и не меняет файлы игры.

## Если обновляешь уже работающий мод

Папка `mods/configs/tanksession_analytics/` должна остаться на месте. В ней находятся накопленные данные, в том числе `battles.jsonl` и `battles.jsonl.pending.jsonl`. При обновлении меняется пакет `.mtmod`; прежние переключатели интерфейса и восстановления сохраняются.

Сохрани резервную копию этой папки отдельно перед переустановкой самой игры или переносом на другой диск. Установщик мода резервирует только заменяемые пакеты, а не всю историю пользователя.

## Первое включение окна в ангаре

Сбор собственных результатов и окно Gameface — отдельные компоненты. Загрузчик **OpenWG Gameface** в поставку TankSession не включён и автоматически не скачивается.

1. Установи подходящий `.mtmod` OpenWG Gameface для «Мира танков» по [инструкции автора](https://gitlab.com/openwg/wot.gameface/-/releases). Не используй вариант для Wargaming World of Tanks.
2. При закрытой игре создай или дополни `mods/configs/tanksession_analytics/settings.json`, сохранив остальные настройки:

```json
{
  "experimental_gameface_ui": true,
  "experimental_cache_recovery": false
}
```

Если файл уже есть, меняй только нужное поле, не заменяй весь файл примером. По умолчанию дополнительный UI и экспериментальное восстановление выключены. Настройки читаются при запуске. Внешний загрузчик при первой регистрации ресурсов может потребовать перезапуск игры — следуй его инструкции.

После загрузки ангара нажми **F8**. В интерфейсе видны только сохранённые бои текущего подтверждённого аккаунта. Пустая история после первой установки ожидаема: мод не импортирует автоматически все прежние бои аккаунта.

## Ручная установка

При закрытой игре проверь SHA-256 файла против строки в `.sha256`, сохрани старые `ru.tanksession.analytics_*.mtmod` вне папки активных модов и скопируй новый пакет в `mods/<точная версия клиента>/`. Оставь одну версию TankSession. Не перемещай другие `.mtmod` и папку с историей.

```powershell
(Get-FileHash ".\ru.tanksession.analytics_1.0.0-rc1.mtmod" -Algorithm SHA256).Hash
```

Имя файла в команде замени на имя из своего архива. Совпадение хеша подтверждает целостность скачанного пакета относительно опубликованной контрольной суммы; оно не является подписью издателя и не заменяет игровой тест.

## Откат

Закрой игру. Убери текущий пакет TankSession из активной папки версии. Из нужной папки `mods/tanksession_backups/` верни прежний `.mtmod` в `mods/<та же версия клиента>/`. Не смешивай два пакета TankSession. История и настройки остаются на месте. При неудачном автоматическом откате установщик явно указывает каталог резервной копии.

## Отключение и удаление

Чтобы отключить окно, при закрытой игре выставь `experimental_gameface_ui` в `false` и перезапусти клиент. Чтобы удалить весь мод, при закрытой игре удали только `ru.tanksession.analytics_<версия>.mtmod` из активной папки `mods/<версия клиента>/`. Историю можно сохранить для последующей установки. OpenWG может использоваться другими модами; его удаление выполняется отдельно по инструкции автора.

После обновления клиента используй пакет, предназначенный для новой версии, и повтори проверку. Перенос старого `.mtmod` в новую папку сам по себе не подтверждает совместимость.

## Об ошибках

При ошибке установки сохрани её текст и версию пакета. Не отправляй весь `python.log`, журналы боёв и `manifest.json` из неизвестных источников в публичные обсуждения. Для игровых проблем используй обезличенную диагностику проекта и список сценариев в [протоколе испытаний](https://github.com/xeemoff/tanksession-analytics/blob/main/docs/CLIENT_VALIDATION_RU.md).

TankSession Analytics — самостоятельный неофициальный проект. Он не опубликован и не одобрен Lesta Games.
