# Проверка TankSession Analytics v0.4.0-rc1 в «Мире танков»

**Это тест-план, а не подтверждение работоспособности в игре.** API и сборка под Python 2.7 пока не проверены на клиенте.

## Шаг 1. Тестирование исходников

Из корня проекта на Windows:

```powershell
py -3 -m unittest discover -s tests -v
py -3 tools/simulate_capture.py
py -3 tools/dashboard.py
```

Откройте http://127.0.0.1:8765/ — это веб-демо на вымышленных боях.

## Шаг 2. Пробная сборка

Нужны Python 3.9+ для скрипта сборки и отдельный Python 2.7 для компиляции игры. Python 2.7 больше не поддерживается; используйте изолированное окружение и только доверенный дистрибутив.

```powershell
py -3 tools/build.py --python2 "C:\\Python27\\python.exe"
py -3 tools/build.py --verify "dist\\ru.tanksession.analytics_0.4.0-rc1.mtmod"
```

**Проверка `--verify` валидирует структуру ZIP, но не корректность игровых событий.**

Перед установкой ознакомьтесь с [правилами запрещённых модификаций](https://lesta.ru/support/ru/products/mt/article/15152/). Выключите игру, сделайте резервную копию модов, поместите созданный файл в `mods/<версия_игры>/` **своего** клиента. Не заменяйте чужие файлы.

## Шаг 3. Проверка реального боя

1. Убедитесь, что в `python.log` появилось `[TankSession] Started;`.
2. Сыграйте обычный бой, дождитесь итогов. Проверьте `[TankSession] Saved battle:`.
3. Найдите `battles.jsonl` по пути из лога и сверьте свои показатели с итоговым экраном.
4. Проверьте несколько боёв, перезапуск и выход до завершения боя. Не должно возникать дублей.
5. `identity_missing` и `account_mismatch` означают, что запись **безопасно пропущена**. Не отключайте эти проверки.
6. Экспериментальное восстановление из кэша оставьте выключенным, пока API текущего клиента не подтверждён.

## Шаг 4. Обезличенный отчёт

Не отправляйте полные логи, настоящие ID аккаунтов или реальную историю своих боёв. Вместо этого выполните:

```powershell
py -3 tools/diagnose_log.py --log "C:\\путь\\к\\python.log"
```

Утилита выводит **только счётчики** сообщений мода. Их можно прислать для разбора.

## Возврат к прежнему состоянию

Если клиент работает нестабильно, закройте игру и удалите только `ru.tanksession.analytics_0.4.0-rc1.mtmod`. Пользовательские журналы не удаляйте без необходимости.

## Когда можно выпускать v0.4

- Успешная компиляция под Python 2.7.
- Подтверждённая загрузка на актуальном клиенте.
- Правильные игровые события и свои данные, без дублей.
- Проверка правил игры, CI и реальный скриншот без личной информации.
