## Сценарии

| Сценарий | Что проверить | Результат |
|---|---|---|
| Загрузка | Клиент запускается, есть Started, нет ошибок TankSession | Не выполнено |
| Обычный бой | Свой танк, исход, урон и опыт совпадают с итоговым экраном | Не выполнено |
| Неполные данные | Поля не превращаются в нули; позднее дополнение сохраняется | Не выполнено |
| Повтор результата | Один логический бой, известные поля не затираются | Не выполнено |
| Перезапуск | Сохранённые данные и ожидание неполного результата читаются | Не выполнено |
| Досрочный выход | Проверена фактическая доставка результата после возврата в ангар | Не выполнено |
| Смена аккаунта | История, цели и уведомления относятся к правильному аккаунту | Не выполнено |
| Реплей | Записи в собственную игровую историю не добавляются | Не выполнено |
| Панель и CSV | Выбранные фильтры совпадают с экспортом | Не выполнено |
| Регистрация Gameface | Layout найден; поведение загрузчика и возможный перезапуск записаны | Не выполнено |
| Окно ангара | F8 открывает, повторное F8 и Esc закрывают; нет невидимой блокировки ввода | Не выполнено |
| Интерфейс Gameface | Кириллица, размеры, мышь, фильтры и график отображаются корректно | Не выполнено |
| Обновление окна | Сохранённый или дополненный бой отражается в текущем фильтре | Не выполнено |
| Смена контекста окна | Выход в бой, отключение и смена аккаунта закрывают окно и очищают старые данные | Не выполнено |
| Отключённый UI | Без opt-in и без loader сбор истории работает независимо от окна | Не выполнено |
| Производительность окна | Измерены время открытия, объём истории и заметные задержки | Не выполнено |
| Удаление мода | Клиент запускается после удаления пакета; история сохранена | Не выполнено |

Если поздний результат вообще не приходит через событие клиента, зафиксируй ограничение. Не включай экспериментальный кэш до отдельного подтверждения его сигнатуры и назначения.

## Доказательства и расхождения

Добавь краткое описание результата, обезличенные счётчики из `tools/diagnose_log.py` и, по желанию, скриншот своих итогов или короткое видео без персональных данных. Полные логи и реальные журналы боёв в репозиторий не добавляй.

После каждого обновления игры повторяй проверку для новой версии. Закрытый протокол относится только к указанному клиенту и указанному пакету.
