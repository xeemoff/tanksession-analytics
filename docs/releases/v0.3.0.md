Предварительный выпуск исходников TankSession Analytics — неофициального проекта для анализа собственных боёв в «Мире танков». Для знакомства достаточно Python 3.9 или новее и браузера. Запустите `python tools/dashboard.py` и откройте http://127.0.0.1:8765/. В комплекте 48 вымышленных боёв на четырёх танках.

### Изменения в версии 0.3.0

- Добавлены фильтры по аккаунту, технике и датам. CSV-экспорт сохраняет всю выбранную историю в UTF-8 с BOM для Excel.
- Панель сравнивает два последовательных периода по 10, 30 или 100 боёв и показывает изменение среднего урона и доли побед.
- График скользящего среднего учитывает полноту данных. Для отображения точки урон должен быть известен хотя бы для 70% боёв в окне.
- В таблице техники появились число боёв, доля побед, средний урон и число результатов с известным уроном.
- Добавлены 13 автотестов. Все 48 тестов прошли локально. Проверены также симуляция отложенного результата, запуск веб-панели и выгрузка CSV.

### Статус игровой интеграции

Игровой адаптер проверен на имитации событий. Запись из актуального клиента «Мира танков» и совместимость пакета с ним ещё предстоит подтвердить. Экспериментальное восстановление результатов через кэш по умолчанию выключено. Сборка для установки в игру в этот выпуск не входит.
