# TankSession Analytics 2.0.0-rc1

Кандидат большой версии с расширенной локальной аналитикой, новым управлением установкой и отдельным движком C++23. Целевой клиент — **«Мир танков» 1.46.0.0**. Статус проверки этого пакета в реальной игре — **pending**. Успешные автоматические проверки и фактическая работа в клиенте учитываются отдельно.

## Аналитика и интерфейс

- Разрезы по картам, уровню, классу и нации техники. Локализованные названия карт и метаданные техники читаются из точных объектов клиента, когда они доступны.
- Календарь активности, распределение результатов по дням недели и часам UTC. Это время получения результата, не измерение времени в бою.
- Экономика по технике с покрытием данных. Итоговые кредиты считаются только по известным значениям; игровая формула чистого итога поддерживает 1/22/24 при полной проверке компонентов. Режим 22 добавлен по справочной цепочке итогового денежного блока; сверка в игре ещё нужна.
- Отчёты за неделю, месяц и всю историю; наблюдения Coach, разброс результатов и предлагаемая цель. Рекомендации описывают сохранённую выборку, не устанавливают причины выигрыша или проигрыша.
- Поиск и сортировка истории, темы, настройка блоков панели, интерактивные диаграммы и отключаемое движение.
- Карточки техники с оригинальными иллюстрациями классов. Чужие игровые изображения в выпуск не включены.

## Установка и данные

- **`manager.cmd`** открывает графическое окно: поиск папки игры, проверка, установка, удаление и возврат прежнего пакета.
- Перед обновлением сохраняются проверенные копии истории/настроек и заменяемых пакетов. История при установке не переписывается.
- Экспорт и импорт полных локальных снимков с манифестом и SHA-256. Импорт заменяет перечисленные файлы после резервирования; объединение двух журналов в эту операцию не входит.
- Проверка новых выпусков по явной кнопке. Данные игры не отправляются; загрузка и запуск обновления остаются действиями пользователя.
- Прежние `install.cmd` и ручное копирование `.mtmod` сохранены. Для готового Windows-архива Python и Node.js не нужны.

## C++23 companion

Новый **отдельный исполняемый файл** выполняет пакетные расчёты по нормализованной истории: суммы, средние, покрытие, выборочная дисперсия, стандартное отклонение, медиана, 90-й процентиль и коэффициент вариации. Python 3-адаптер читает журнал штатным валидатором, ограничивает одним подтверждённым аккаунтом и разрешает идентичность техники перед отправкой числового протокола в C++.

Нативная часть не загружается в процесс игры и не заменяет Python 2.7-адаптер. Для неё поставляется отдельный Native-архив; работа через Python-адаптер требует Python 3.9+. CMake, GoogleTest, проверки совпадения с Python, санитайзеры и бенчмарки входят в исходники и CI. Детали — [NATIVE_CORE_RU.md](https://github.com/xeemoff/tanksession-analytics/blob/v2.0.0-rc1/docs/NATIVE_CORE_RU.md).

## Файлы выпуска

| Архив или пакет | Для чего нужен |
|---|---|
| `TankSession_Analytics_2.0.0-rc1_Windows.zip` | Установка и управление модом через `manager.cmd`; распаковать весь архив |
| `ru.tanksession.analytics_2.0.0-rc1.mtmod` | Ручная установка в папку `mods/<версия клиента>/` |
| `TankSession_Analytics_2.0.0-rc1_Preview.zip` | Браузерная демонстрация через `demo_hangar.cmd`, нужен Python 3.9+ |
| `TankSession_Analytics_2.0.0-rc1_Native_Windows_x64.zip` | C++23-движок и Python 3-адаптер для Windows x64 |
| `TankSession_Analytics_2.0.0-rc1_Native_Linux_x64.zip` | C++23-движок и Python 3-адаптер для Linux x64; совместимость зависит от системных библиотек |

К каждому файлу приложена контрольная сумма `.sha256`: всего десять файлов. Для обычного обновления мода достаточно Windows-архива.

## Совместимость и проверки

JSONL сохраняет schema 1. Старые строки читаются без перезаписи и без вымышленных метаданных. Профили сохраняют обратное чтение прежних настроек. При неоднозначной идентичности техника не получает недостоверную оценку Coach или достижение цели.

Клиентские поля сопоставлены со справочным исходником **1.46.0.0_CT**, закреплённым за коммитом `e241d4d04d610f0747271ff6f044ee809a607b53`. Это источник для реализации, не доказательство совпадения с установленным клиентом.

Стабильный выпуск **2.0.0** блокируется до заполнения живого протокола с хешем именно проверенного `.mtmod`. Окно Gameface и экспериментальное восстановление результатов по умолчанию выключены; внешний загрузчик OpenWG устанавливается отдельно.
