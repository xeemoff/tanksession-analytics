# Как опубликовать TankSession Analytics

**Текущая версия — 2.0.0-rc2: кандидат с исправлениями по испытанию RC1 на клиенте 1.46.0.0.** Исходный код публичный. Точный установленный RC1 подтверждён хешем, частичные результаты и расхождения записаны в [протоколе](CLIENT_VALIDATION_RU.md). Полный CI относится к конкретному коммиту; исправления RC2 требуют повторного игрового испытания. Стабильный выпуск 2.0.0 пока не подтверждён.

## Можно уже сейчас

- Опубликовать **свой собственный** исходный код в GitHub под MIT (он уже публичный).
- Демонстрировать локальную веб-панель на синтетических данных.
- Публиковать явно обозначенный предварительный выпуск с Windows-архивом, `.mtmod`, контрольными суммами и известными ограничениями. Для этой версии указывать канал prerelease, не выдавать кандидата за стабильный выпуск.
- Указывать только сценарии и версии из [протокола испытаний](CLIENT_VALIDATION_RU.md). Не используйте слова «официальный», «одобрен Lesta», «полностью совместим» или «стабильный релиз» без основания.

## Перед стабильным выпуском

1. Проверить на текущем клиенте, что загрузка и запись собственных результатов действительно работают. Записать совместимую версию клиента, повторить проверку после обновлений.
2. Сверить содержимое мода с [официальным перечнем запрещённых модификаций](https://lesta.ru/support/ru/products/mt/article/15152/). **Никакой помощи при прицеливании и дополнительной информации о противнике в бою.** Наше назначение — только статистика после боя.
3. Учесть [лицензионное соглашение](https://legal.lesta.ru/eula/): не включать чужой код, байткод, текстуры, шрифты, логотипы и другие игровые ресурсы. Если есть сомнения в допустимости конкретных хуков и распространения пакета, запросить разрешение/разъяснение у поддержки Lesta.
4. Убедиться, что в архив не попали реальные `battles.jsonl`, данные аккаунтов, `python.log`, персональные файлы или настройки.
5. Создать воспроизводимую сборку, проверить её структуру, хеш SHA-256, установку и удаление. Не считать результат `--verify` доказательством совместимости.
6. Дать понятную инструкцию по установке/удалению, конфиденциальности и список ограничений.

В проекте подготовлен [процесс выпуска](RELEASE_RU.md). Сборка Windows-архива и публикация стабильного канала проверяют `release-validation.json`: подтверждённый клиент, дату, закрытые сценарии и SHA-256 именно испытанного `.mtmod`. Автоматический CI не меняет этот статус. Если игровой тест ещё не выполнен, выпуск сохраняет статус кандидата.

## Публикация на официальном форуме

См. [правила публикации модификаций](https://forum.tanki.su/topic/2200656-правила-публикации-модификаций/), проверенные 26.11.2026. Перед размещением темы повторно сверяй актуальный текст.

- Создать **собственную** тему в соответствующем разделе; не помещать свой мод в чужую тему.
- Указать версию поддерживаемого клиента **в начале заголовка**. Не использовать `[ALL]`, пока совместимость с разными версиями не доказана.
- Добавить описание, прямую ссылку на скачивание, инструкцию установки, реальные скриншоты для интерфейсных изменений (не более 3), известные ограничения и данные автора.
- Публикация проходит проверку администрацией раздела. После патчей необходимо поддерживать совместимость; при устаревании мод могут перенести в архив.
- Для первой публикации не используйте демоданные в качестве свидетельства работы в настоящей игре.

## Пример безопасного заголовка после тестирования

`[ВЕРСИЯ_КЛИЕНТА] TankSession Analytics — личная аналитика завершённых боёв`

Используйте только реально проверенную версию клиента. На GitHub можно оформить GitHub Release с отдельным файлом `.mtmod` и контрольной суммой; сам GitHub-репозиторий с исходниками при этом может оставаться публичным.

Официальный перечень запрещённых модификаций отдельно рассматривает моды, действующие только в ангаре. Назначение TankSession — собственная послебоевая аналитика. Соответствие этому назначению не является индивидуальным одобрением мода администрацией.

## Дисклеймер

TankSession Analytics — самостоятельный неофициальный проект. Он не разработан, не опубликован и не одобрен Lesta Games. Названия игр принадлежат своим правообладателям. Код проекта предоставляется без гарантий. Публикуйте только материалы, права на которые вам принадлежат.
