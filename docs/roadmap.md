# План развития TankSession Analytics

## Сейчас: 0.4.0-rc9 — надёжность и наблюдаемая история

### Реализовано
- [x] JSONL-журнал, проверка принадлежности аккаунту, дополнение неполных записей, защита от повторного учёта.
- [x] React/TypeScript, экспериментальный Gameface, фильтры техники и периодов 10/30/100, постраничная история.
- [x] Session Coach: среднее, медиана, полнота выборки, локальные рекорды и цели.
- [x] Вкладка «Сводка», график каждого боя, серии исходов, помощь, сводки по дням/технике, индикатор незакрытых ожиданий.
- [x] Python-тесты, проверка TypeScript, Playwright, CPython 2.7 и воспроизводимая сборка кандидатов.

### Подтверждено в игре на rc4–rc8
- [x] Сохранение обычного завершённого боя и совпадение первой записи с официальным экраном.
- [x] Открытие Gameface через F8, закрытие крестиком, фильтры, три вкладки, сохранение старой истории при обновлении, центрирование.
- [x] Подключение дополнительного обработчика результатов в ангаре и ответы кэша (старые ожидания не восстановлены).
