# План развития TankSession Analytics

## Сейчас: 0.4.0-rc9 — надёжность и наблюдаемая история

### Реализовано
- [x] JSONL-журнал, проверка принадлежности аккаунту, дополнение неполных записей, защита от повторного учёта.
- [x] React/TypeScript, экспериментальный Gameface, фильтры техники и периодов 10/30/100, постраничная история.
- [x] Session Coach: среднее, медиана, полнота выборки, локальные рекорды и цели.
- [x] Вкладка «Сводка», график каждого боя, серии исходов, помощь, сводки по дням/технике, индикатор незакрытых ожиданий.
- [x] Python-тесты, проверка TypeScript, Playwright, CPython 2.7 и воспроизводимая сборка кандидатов.

### Подтверждено в игре на rc4–rc8
- [x] Сохранение обычного завершённого боя и совпадение первой записи с официальным экраном.
- [x] Открытие Gameface через F8, закрытие крестиком, фильтры, три вкладки, сохранение старой истории при обновлении, центрирование.
- [x] Подключение дополнительного обработчика результатов в ангаре и ответы кэша (старые ожидания не восстановлены).

## Следующие этапы (план, не реализованные функции)

- **0.5:** проверенные метрики карт, выживаемости, стрельбы и экономики; стабильные идентификаторы техники; базовый и бонусный опыт; явная поддержка старых записей.
- **0.6:** более глубокие персональные выводы и сравнение сессий по достаточной выборке; не выводить причины без подтверждённых данных.

Номера будущих версий условны. [История изменений](../CHANGELOG.md) описывает уже реализованные возможности, а [протокол испытаний](CLIENT_VALIDATION_RU.md) — фактический объём проверки.

- [ ] Сравнение сессий: сопоставимые режимы и достаточные выборки, без предположений о причинах изменений.
- [ ] Редактирование целей из интерфейса, валидация и безопасное сохранение с восстановлением после ошибки.
- [ ] Сохранение настроек представления и фильтров, экспорт актуального снимка.
- [ ] Установщик с проверкой версии клиента, резервной копией и откатом; сохранить пользовательские данные.
- [ ] Пройти CI, включая Windows, Python 2.7, браузерные сценарии и воспроизводимость пакета.
- [ ] Пройти игровой протокол на целевой версии клиента; подтвердить реальные поражения, отложенные результаты, переходы и изоляцию аккаунтов.
- [ ] Актуализировать README, схему архитектуры, снимки, changelog и инструкцию установки.

Новая функциональность в этом списке не считается реализованной до появления соответствующих изменений и результатов испытаний.
