# План развития TankSession Analytics

## Сейчас: 1.0.0-rc2 — завершение программного объёма

Программные изменения этапов 0.5–0.7 объединены в кандидате 1.0.0-rc2. В нём реализованы три пробела, найденные аудитом RC1: отдельная идентичность техники, бонусный опыт и расчёт чистых кредитов в явно поддержанном сценарии. Целевой клиент — **1.46.0.0**, статус живого протокола новой версии — **pending**. Полный CI должен подтвердить именно итоговый коммит RC2; [отчёт готовности](READINESS_1_0_0_RU.md) сохраняет историю аудита и отдельное дополнение о текущей версии.

### Реализовано в коде

- [x] Локальный JSONL-журнал, принадлежность подтверждённому аккаунту, дополнение неполных записей и дедупликация.
- [x] Ограниченная очередь готовых результатов, повторы и таймауты восстановления; очистка старого контекста при смене аккаунта.
- [x] React/TypeScript, Gameface, фильтры, графики, Session Coach, рекорды, полнота выборки и цели.
- [x] История всего загруженного журнала по пять строк на страницу и подробности результата.
- [x] Необязательные поля карты, уничтоженной техники, выживания, стрельбы, базового опыта и начисленных кредитов; показатели считают только известные значения.
- [x] Отдельный `vehicle_id`, стабильный selector и понятная подпись; проекция прежней истории только своего аккаунта, точные однозначные соответствия, изоляция неоднозначных групп.
- [x] Бонусный опыт сверх базовой строки при известных компонентах; отрицательная или неполная разность остаётся неизвестной.
- [x] Чистые кредиты по полной формуле поддержанного результата 1/24: одна машина, подтверждённый avatar, известные начисления, удержания, события и фактические кредитные расходы.
- [x] Разделение сессий по паузе от 60 минут между получениями результатов; сравнение при достаточной сопоставимой выборке.
- [x] Личные профили аккаунтов, сохранение фильтров и вида, редактор целей, CSV без ID аккаунта и боя.
- [x] Атомарная запись профиля с предыдущей копией; сохранение старых целей и игровой истории.
- [x] Браузерный просмотр собственной истории только для чтения по умолчанию; явный `--allow-write` для записи и временный профиль демо.
- [x] Windows-установщик с SHA-256, проверкой назначения пакета, резервированием прежней версии и откатом.
- [x] Упаковка Windows ZIP, выпуск по тегу и автоматический gate для стабильной версии.
- [x] Автоматические сценарии Python, TypeScript, браузера, CPython 2.7 и установщика Windows. Фактический результат зависит от CI конкретного коммита.

Карта может показываться ключом `arena:<ID типа карты>`. Кредитный итог не оценивает складские предметы, золото, боны, будущую копилку или неподдержанные режимы. Все игровые сопоставления основаны на закреплённом справочном коде **1.46.0.0_CT** и остаются неподтверждёнными до сверки с установленным клиентом.

### Закрытие программных пробелов аудита RC1

| Пробел | Реализация RC2 | Что остаётся проверить |
|---|---|---|
| Идентичность техники и старая история | `vehicles.py`, отдельное поле, selector/label, проекция без перезаписи, проверяемая ревизия того же боя | Реальные источники типа, сохранность выборов и разделение неоднозначных подписей в клиенте |
| Бонусный опыт | `xp_bonus = personal.xp - (originalXP - achievementXP)` при известных допустимых значениях | Совпадение базовой строки и полученной разности с итогами игры |
| Чистые кредиты | Полная формула кредитного итога поддержанного сценария с явными ограничениями | Реальные компоненты, округление, положительный/отрицательный итог, неизвестное при нехватке данных |

Наличие кода закрывает программные пробелы в указанном объёме. Прохождение CI и живые испытания фиксируются отдельно; номер RC2 не переносит результаты старых пакетов на новый.

### Ранее подтверждено в игре на rc4–rc8

- [x] Обычный завершённый собственный бой записан; первая запись сверена с официальным результатом.
- [x] Gameface открывается через F8, закрывается крестиком, работают часть фильтров и вкладок; центрирование подтверждено в rc8.
- [x] Ранее записанная история сохранена при обновлениях и перезапусках.
- [x] Обработчик результатов ангара подключается, кэш отвечает; старые ожидания не восстановлены.

Эти результаты относятся к прежним пакетам. [Протокол](CLIENT_VALIDATION_RU.md) сохраняет версии, даты и границы проверки.

## После 1.0.0

Поддержка обновлений клиента, исправления по воспроизводимым сообщениям и уточнение дополнительных метрик. Локализованные названия карт, экономика других режимов и другие валюты добавляются только при подтверждённых источниках.
