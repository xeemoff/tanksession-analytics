# Как запустить TankSession Analytics v0.4.0-rc1

**Важно:** это исходники экспериментального проекта. Демоверсия использует вымышленные данные. Работу в актуальном клиенте «Мира танков» ещё предстоит подтвердить.

## 1. Быстрая проверка

Установи Python 3.9+ и открой терминал в корневой папке проекта:

```powershell
python -m unittest discover -s tests -v
python tools/simulate_capture.py
python tools/dashboard.py
```

Открой **http://127.0.0.1:8765/**. На странице по умолчанию 48 синтетических боёв.

## 2. Что попробовать в версии 0.3

1. Выбери «Аккаунт» и «Танк» — статистика обновится после кнопки «Показать».
2. Выбери окно **10**, **30** или **100** боёв: сравнение появится только при наличии двух полных последовательных окон.
3. Посмотри «Скользящий средний урон». Если данных мало, появится понятное сообщение, а не вымышленный ноль.
4. Проверь сводную таблицу «Эффективность по танкам».
5. Нажми **«Экспорт CSV»** — в файл попадут только результаты, соответствующие текущим фильтрам.

## 3. Как указать свой файл

Данные в игровом клиенте сначала нужно **реально записать и проверить** — автотесты не гарантируют этого.

```powershell
python tools/dashboard.py --data "D:\your-folder\battles.jsonl"
```

Фактический путь к файлу будет указан в `python.log` игрового адаптера. Имена каталогов и API клиента могут отличаться между версиями.

## 4. Сборка игрового пакета (пока экспериментальная)

См. [docs/integration.md](docs/integration.md) и сначала проверь свою версию клиента. Если у тебя имеется **изолированный Python 2.7**:

```powershell
python tools/build.py --python2 "C:\Python27\python.exe"
```

Ожидаемый путь после сборки: `dist/ru.tanksession.analytics_0.4.0-rc1.mtmod`. Сборка **не устанавливается автоматически**. Готовый `.mtmod` не предоставлен, проверка работы на текущем клиенте ещё не проведена.

## 5. Что прислать для проверки интеграции

После теста на своём компьютере можно показать только записи `python.log`, связанные с `[TankSession]`, **без логинов, токенов, ID аккаунтов и личных данных**. При необходимости замени идентификаторы на вымышленные. Не публикуй целиком игровые логи или реальную историю боёв.

**Пробная установка и диагностика:** [docs/CHECK_CLIENT_RU.md](docs/CHECK_CLIENT_RU.md).
