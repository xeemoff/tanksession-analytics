# Быстрый старт — TankSession Analytics 1.0.0-rc1

**Это кандидат для испытаний на клиенте 1.46.0.0.** Новые возможности ещё не проверены на этой сборке в реальной игре. Предыдущие результаты rc4–rc8 описаны в [протоколе](docs/CLIENT_VALIDATION_RU.md).

## Обновить установленный мод

1. Закрой игру. Скачай `TankSession_Analytics_1.0.0-rc1_Windows.zip` из [выпуска нужной версии](https://github.com/xeemoff/tanksession-analytics/releases) или артефакта нужного успешного [CI-запуска](https://github.com/xeemoff/tanksession-analytics/actions/workflows/tests.yml) и распакуй весь архив.
2. Запусти **install.cmd**, введи папку игры и точную версию клиента. Например: `C:/Games/Tanki` и `1.46.0.0`. Установщик проверит файл, сохранит прежний пакет и выполнит замену.

**Не удаляй `mods/configs/tanksession_analytics/`: это история и настройки.** Python и Node.js для готового установочного архива не нужны. Старые настройки сохранятся. При ручной установке оставь одну версию TankSession в `mods/<версия клиента>/`. [Полная инструкция, проверка без установки и откат](docs/INSTALL_RU.md).

При первой установке для окна ангара нужны отдельно OpenWG Gameface и настройка `experimental_gameface_ui: true`. Загрузчик не входит в архив. Окно открывается **F8** из ангара. Подключение описано в [GAMEFACE_RU.md](docs/GAMEFACE_RU.md); восстановление через кэш и дополнительный UI по умолчанию выключены.

## Что посмотреть после открытия

- **История:** листай по пять боёв и открывай детали. Старые записи могут не содержать новых метрик; прочерк означает отсутствие данных.
- **Сводка:** исходы, помощь, доступные дополнительные метрики и сессии. Сессия разделяется паузой от 60 минут между получениями результатов, а не фактическими стартами боёв.
- **Настройки:** сохрани выбранную технику, период, стартовую вкладку, плотность и контраст; добавь цель по среднему урону или выгрузи CSV. Экспорт содержит всю историю выбранной техники текущего аккаунта.

Для достижения цели нужен полный период с известным уроном в каждом бою. Для сравнения сессий — минимум десять боёв в каждой, одна известная машина и один режим. При меньшей выборке интерфейс показывает причину отсутствия сравнения.

## Посмотреть в браузере без установки в игру

В артефакте `tanksession-hangar-preview-...` распакуй вложенный `TankSession_Analytics_1.0.0-rc1_Preview.zip`. Нужны Python 3.9+ и браузер. Запусти **demo_hangar.cmd** или:

```powershell
python tools/preview_ui.py --demo
```

Выбери IS-7 и окно 10 для готового сравнения периодов. Демобои вымышленные, источник явно помечен. Настройки и экспорт демонстрации используют временную папку. Это просмотр React в браузере, который не устанавливает мод и не запускает Gameface.

Если скачаны исходники, сначала собери интерфейс с Node.js 20+:

```powershell
cd ui
npm ci
npm run build
cd ..
python tools/preview_ui.py --demo
```

Свою историю открывай так:

```powershell
python tools/preview_ui.py --data "D:/your-folder/battles.jsonl" --account "ID_АККАУНТА"
```

Этот режим разрешает только чтение. Для сохранения настроек, целей и CSV добавь `--allow-write`; файлы создаются рядом с журналом. Перед записью в папку, используемую игровым модом, закрой игру. `--port 0` выбирает свободный порт, `--no-browser` оставляет ручное открытие адреса. Остановка сервера — Ctrl+C.

## Где находятся данные

| Данные | Место в установленной игре |
|---|---|
| История | `mods/configs/tanksession_analytics/battles.jsonl` |
| Ожидания результата | `battles.jsonl.pending.jsonl` рядом с историей |
| Прежние настройки интеграции | `settings.json` рядом с историей |
| Личный вид и цели | Подпапка `profiles/`, отдельный JSON для аккаунта и предыдущая копия `.bak` |
| Экспорт | Подпапка `exports/`, отдельный CSV для каждого запроса |
| Прежние пакеты при обновлении | `mods/tanksession_backups/` |

Прежний `goals.json` продолжает читаться до сохранения личного набора целей. Редактор его не переписывает. Реальный путь журнала игровой адаптер показывает в строке `[TankSession] Started; local data path:`.

## Проверить код и сборку

```powershell
python -m unittest discover -s tests -v
python tools/simulate_capture.py
python tools/generate_ui_fixtures.py --check
```

TypeScript, Playwright и упаковка описаны в [README](README.md). Реальные проверки Python 2.7 и установщика PowerShell выполняются в соответствующих CI-средах. Пропуск теста в другой среде не считается его прохождением.

## Если результат не появился

Проверь версию установленного пакета, подтверждение своего аккаунта и выбранную технику. Счётчик ожиданий показывает незакрытые результаты; клиент может больше не предоставлять часть старых боёв. Исправление очереди не восстанавливает отсутствующие у клиента данные автоматически.

Обезличенная диагностика:

```powershell
python tools/diagnose_log.py --log "D:/your-folder/python.log" --json
```

Для обсуждения ошибки достаточно версии клиента и мода, сценария и счётчиков. Полную историю и идентификаторы в публичные материалы не добавляй. Следующие игровые шаги — в [плане испытаний](docs/CHECK_CLIENT_RU.md).

## Прежняя панель и обслуживание

`demo_dashboard.cmd` и `start_dashboard.cmd` сохранены. Через терминал:

```powershell
python tools/launch_dashboard.py --demo
python tools/launch_dashboard.py --game-dir "D:/Games/Tanki"
python tools/maintain_data.py --data "D:/your-folder/battles.jsonl"
```

Последняя команда только проверяет журнал. Для компактирования добавь `--compact`, предварительно закрыв игру и панели; исходные байты сохраняются в резервную копию.
