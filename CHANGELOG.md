# История изменений

## 0.4.0-rc1 — кандидат для тестирования (18 ноября 2026)

- Запрещена запись игрового результата без подтверждённого ID аккаунта.
- Не сохраняем отложенный результат при конфликте аккаунта с сохранённым контекстом боя.
- Сбрасываем старый ID при событии входа в другой аккаунт.
- Метаданные модификации используют корень `<root>`.
- Инструмент сборки проверяет наличие всех скомпилированных модулей и поддерживает `--verify` для `.mtmod`.
- Добавлена безопасная сводка `python.log` — только счётчики, без ID и путей.
- Всего 60 автотестов, игровой клиент ещё не проверен.

## 0.3.0 — 18 ноября 2026 (предварительная версия для разработчиков)

### Новое

- Добавлен модуль `analytics.py`: детерминированная сортировка и фильтрация истории по танку, аккаунту и датам; проверка ISO-дат.
- Сравнение **двух непересекающихся полных периодов** по 10, 30 или 100 боёв: средний урон и процент побед с дельтой в процентных пунктах.
- Скользящий средний урон с порогом 70% известных результатов в окне; отсутствующие данные не подменяются нулями.
- Таблица техники с числом боёв, процентом побед, средним уроном и полнотой измерений.
- CSV-экспорт с текущими фильтрами, UTF-8 BOM для Excel и защитой текстовых полей от интерпретации как формул.
- Фильтр по аккаунту, более информативная веб-панель и настройка размера окна сравнения.
- Базовая защита localhost HTTP-страницы: проверка `Host`, заголовки `no-store`, `nosniff`, CSP и запрет фреймов.
- 13 новых тестов; всего **48 автоматических тестов** на синтетических данных и имитации игрового клиента.
- Обновлена русскоязычная документация, подготовлены материалы для GitHub.

### Ограничения

- Реальный клиент Lesta не тестировался, игровой адаптер по-прежнему экспериментальный.
- Встроенного Gameface/React-окна пока нет: графики отображаются в браузере на `localhost`.
- `.mtmod` не создавался без отдельного интерпретатора Python 2.7 и не включён в релиз.
- Не подтверждены API игровых событий и отложенного кэша результатов.

## 0.2.0 — 18 ноября 2026 (предварительная версия для разработчиков)

- Исправлено приведение чисел при расчётах (регрессия с уронами в виде строк).
- Улучшена защита от дублей и повреждённых записей JSONL; сохранение с `flush/fsync`.
- Добавлен журнал незавершённых боёв и экспериментальное восстановление результатов из кэша (по умолчанию выключено).
- Добавлены имитационные тесты игрового адаптера, отдельная симуляция, безопасная выгрузка обработчиков.
- Итог версии: 35 автоматических тестов. Реальная совместимость с игровым клиентом не подтверждалась.

## 0.1.0 — 18 ноября 2026

- Первый прототип локальной истории результатов, общей статистики, браузерной страницы и тестов.
