# История изменений

## 0.4.0-rc7 — положение и фон окна (26 ноября 2026)

- После первого запроса интерфейса выполняется одна необязательная попытка центрирования через `WindowImpl.center()`. Отказ API не препятствует отображению данных.
- В игровом режиме панель сохраняет высоту при переключении разделов; фон вокруг неё сделан прозрачным в CSS. Фактическое наложение Gameface требует испытания.
- Уточнены надписи графика и целей для совместимости с нативной вёрсткой; добавлены тесты успешного и неуспешного центрирования.
- Зафиксировано испытание rc6 в клиенте. Расчёты и формат журнала не изменены.

## 0.4.0-rc6 — навигация без колеса мыши (26 ноября 2026)

- Вкладки прогресса, динамики/целей и истории; история и выбор техники имеют постраничную навигацию.
- Пояснение расчёта заменяет содержимое карточки, не удлиняя её. Исправлены цвет кнопок и часть сложных переносов текста.
- Для проверенного ключа Т-34 добавлена отображаемая подпись без изменения фильтров и истории.
- Зафиксировано частичное испытание rc5 в реальном Gameface. Исправления rc6, положение окна и остальные сценарии требуют игровой проверки.

## 0.4.0-rc5 — разбор прогресса и рекорды (21 ноября 2026)

### Новое

- Разбор прогресса на одной машине: средний урон, медиана и их изменения для двух полных непересекающихся периодов 10/30/100.
- Явная нехватка боёв, неизвестного урона или определённой техники. Разные известные типы боёв блокируют сравнение.
- Лучший урон и лучшее полное скользящее окно в локальной истории. Первая запись и равенство максимуму не объявляются новым рекордом; сравнение выполняется до округления.
- Объяснение расчёта, объёма выборки, порядка получения результатов и ограничений. Опыт не используется для выводов о прогрессе.
- Добавочный проверяемый объект coach в протоколе 1. Поддержаны старые снимки без него; ID аккаунтов и арен не передаются.
- В демо сохранены 48 вымышленных боёв, из них 24 на IS-7 для показа готового сравнения.

### Исправления

- Определение собственного аккаунта через доступные клиентские источники с сохранением подтверждённого контекста ангара.
- Обработка personal по ID аккаунта и единственной личной записи рядом с avatar; неоднозначные кандидаты отклоняются.
- Чтение настроек и целей в UTF-8 с BOM из Windows при сохранении проверок типов и размеров.
- Новый модуль включён в оба пакета: CPython 2.7 mtmod и готовый браузерный просмотр.

### Проверки и границы

- Исправленным rc4 подтверждено сохранение одного реального боя на клиенте 1.46.0.0; сведения и хеш приведены в CLIENT_VALIDATION_RU.md.
- Добавлены проверки расчётов, JSON-границы, состояний интерфейса, кодировки и сценарии браузера. Точный результат автоматических проверок относится к CI выбранного коммита.
- Native Gameface, новый rc5 и полный набор игровых сценариев требуют отдельного испытания. Опциональное окно и восстановление через кэш остаются выключены по умолчанию.
- Это описательная аналитика сохранённой истории, без причинных выводов о навыке или прогнозов.

## 0.4.0-rc4 — интерфейс React и экспериментальное окно Gameface (19 ноября 2026)

### Новое

- Интерфейс на React 18.2.0 и TypeScript: техника, окна 10/30/100, показатели, график, сравнение, цели, последние бои и качество истории.
- Общая Python-модель снимка и проверяемый JSON-контракт. Подтверждённый аккаунт задаёт Python; ID аккаунтов и арен не уходят в UI.
- Необязательный адаптер внешнего OpenWG Gameface для ангара: F8, Esc, команды, подписки и очистка при смене контекста.
- Настройка `experimental_gameface_ui`, выключенная по умолчанию. Наличие совместимого меню модов необязательно.
- Локальный браузерный просмотр и готовый архив с ресурсами, которому для запуска не нужен Node.js.
- CI для TypeScript, общих Python/JS примеров и Playwright; снимок браузерного демо и архив просмотра.
- Пакет включает 11 Python-модулей, HTML, JS, CSS, лицензии зависимостей и декларацию Layout. Внешний loader не включён.

### Надёжность

- Проверки входных команд, лимитов, неизвестных значений и точного диапазона чисел JavaScript.
- Последний запрос фильтра сохраняется; поздний ответ не вытесняет новые данные. Ошибка очищает старый снимок.
- Контекст окна проверяется без пересчёта статистики; старые callback не могут открыть или обновить другое окно.
- Расчёт графика и сравнения ограничен необходимым хвостом истории с сохранением абсолютных номеров боёв.
- Реальные HTTP-тесты нового сервера, проверки lifecycle через имитацию Wulf и дополнительный runtime-сценарий CPython 2.7.

### Границы

- Работа Gameface, события и игровые результаты в актуальном клиенте Lesta ещё не подтверждены.
- Браузерный снимок и Playwright подтверждают отображение в Chromium, не в игровом движке.
- OpenWG Gameface устанавливается отдельно и может перезапустить клиент при обновлении карты ресурсов по своей инструкции.
- Снимок рассчитывается синхронно; влияние большой истории на игровой клиент требует измерения.

## 0.4.0-rc3 — корректные результаты и проверяемая сборка (19 ноября 2026)

### Исправления

- Неполный результат дополняется последующим событием; история восстанавливает ревизии после перезапуска и учитывает один логический бой.
- Известные конфликтующие показатели не перезаписываются. Pending закрывается только при известных исходе, уроне и опыте.
- Неверные типы, неизвестные схемы, огромные числа и повреждённые строки не ломают панель; чтение не меняет исходник.
- Цели оцениваются отдельно по аккаунтам, проверяются до округления среднего. Названия целей демо согласованы с историей.
- Лимит восстановления учитывает вызовы с исключением. Поздние callback и таймеры защищены токенами запроса и входа.
- Ангарная сводка относится к текущему аккаунту. Диагностика объясняет отсутствие идентичности, недоступность replay API и стадию сбоя запуска.
- При потере доступа к журналу панель перестаёт показывать старый кэш как успешно прочитанные данные.

### Новое

- Помощник запуска на Python 3, выбор папки через Tkinter, start_dashboard.cmd и demo_dashboard.cmd.
- Состояние источника, время последнего результата и счётчики неполных, отклонённых и дополненных записей в панели.
- Реальные HTTP-регрессии, проверки CSV и сценариев запуска.
- CI для Python 3 на Ubuntu/Windows и отдельная сборка официального CPython 2.7.18 с закреплённым SHA-256.
- Пять runtime-сценариев Python 2.7, проверка всех девяти модулей и сравнение двух независимых сборок.
- Фиксированные параметры упаковки, относительные пути байткода, контрольная сумма пакета и CI artifact.
- Документация архитектуры на русском языке и шаблон протокола проверки игрового клиента.

### Границы

- Автоматическая проверка состава и заголовков не исполняет произвольный архив и не доказывает работу в игре.
- Реальная совместимость и игровые поля ещё не подтверждены. Кэш восстановления остаётся выключенным по умолчанию.
- Время по-прежнему означает получение результата, техника сопоставляется по имени, запись журнала рассчитана на один процесс.

## 0.4.0-rc1 — кандидат для тестирования (18 ноября 2026)

- Запрещено записывать результаты в игровом адаптере без подтверждённого ID аккаунта.

- Добавлены 12 регрессионных тестов, всего **60**.
- Реальную совместимость с клиентом и компиляцию Python 2.7 ещё необходимо подтвердить.


## 0.3.0 — 18 ноября 2026 (предварительная версия для разработчиков)

### Новое

- Добавлен модуль `analytics.py`: детерминированная сортировка и фильтрация истории по танку, аккаунту и датам; проверка ISO-дат.
- Сравнение **двух непересекающихся полных периодов** по 10, 30 или 100 боёв: средний урон и процент побед с дельтой в процентных пунктах.
- Скользящий средний урон с порогом 70% известных результатов в окне; отсутствующие данные не подменяются нулями.
- Таблица техники с числом боёв, процентом побед, средним уроном и полнотой измерений.
- CSV-экспорт с текущими фильтрами, UTF-8 BOM для Excel и защитой текстовых полей от интерпретации как формул.
- Фильтр по аккаунту, более информативная веб-панель и настройка размера окна сравнения.
- Базовая защита localhost HTTP-страницы: проверка `Host`, заголовки `no-store`, `nosniff`, CSP и запрет фреймов.
- 13 новых тестов; всего **48 автоматических тестов** на синтетических данных и имитации игрового клиента.
- Обновлена русскоязычная документация, подготовлены материалы для GitHub.

### Ограничения

- Реальный клиент Lesta не тестировался, игровой адаптер по-прежнему экспериментальный.
- Встроенного Gameface/React-окна пока нет: графики отображаются в браузере на `localhost`.
- `.mtmod` не создавался без отдельного интерпретатора Python 2.7 и не включён в релиз.
- Не подтверждены API игровых событий и отложенного кэша результатов.
