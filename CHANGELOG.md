# История изменений

## 0.4.0-rc3 — корректные результаты и проверяемая сборка (19 ноября 2026)

### Исправления

- Неполный результат дополняется последующим событием; история восстанавливает ревизии после перезапуска и учитывает один логический бой.
- Известные конфликтующие показатели не перезаписываются. Pending закрывается только при известных исходе, уроне и опыте.
- Неверные типы, неизвестные схемы, огромные числа и повреждённые строки не ломают панель; чтение не меняет исходник.
- Цели оцениваются отдельно по аккаунтам, проверяются до округления среднего. Названия целей демо согласованы с историей.
- Лимит восстановления учитывает вызовы с исключением. Поздние callback и таймеры защищены токенами запроса и входа.
- Ангарная сводка относится к текущему аккаунту. Диагностика объясняет отсутствие идентичности, недоступность replay API и стадию сбоя запуска.
- При потере доступа к журналу панель перестаёт показывать старый кэш как успешно прочитанные данные.

### Новое

- Помощник запуска на Python 3, выбор папки через Tkinter, start_dashboard.cmd и demo_dashboard.cmd.
- Состояние источника, время последнего результата и счётчики неполных, отклонённых и дополненных записей в панели.
- Реальные HTTP-регрессии, проверки CSV и сценариев запуска.
- CI для Python 3 на Ubuntu/Windows и отдельная сборка официального CPython 2.7.18 с закреплённым SHA-256.
- Пять runtime-сценариев Python 2.7, проверка всех девяти модулей и сравнение двух независимых сборок.
- Фиксированные параметры упаковки, относительные пути байткода, контрольная сумма пакета и CI artifact.
- Русскоязычный инженерный кейс и незаполненный протокол проверки реального клиента.

### Границы

- Автоматическая проверка состава и заголовков не исполняет произвольный архив и не доказывает работу в игре.
- Реальная совместимость и игровые поля ещё не подтверждены. Кэш восстановления остаётся выключенным по умолчанию.
- Время по-прежнему означает получение результата, техника сопоставляется по имени, запись журнала рассчитана на один процесс.

## 0.4.0-rc2 — функциональная и инженерная доработка (18 ноября 2026)

- Реализованы персональные цели по среднему урону за N боёв, с индикацией неполных данных.
- Оптимизировано скользящее среднее: один проход вместо повторного пересчёта окон.
- Добавлены кэш чтения JSONL, инструмент ручного обслуживания/резервного копирования и бенчмарк 100 000 боёв.
- Определение каталога игры теперь требует проверенного `paths.xml` (текущий каталог / `ResMgr.appDirectory()`).
- Подготовлен русскоязычный чек-лист публичной публикации и 69 тестов.
- Совместимость и использование в настоящем клиенте всё ещё не подтверждены.

## 0.4.0-rc1 — кандидат для тестирования (18 ноября 2026)

- Запрещено записывать результаты в игровом адаптере без подтверждённого ID аккаунта.
- Результат, начатый на другом аккаунте, теперь пропускается без удаления ожидающей записи.
- Обработчик нового входа сбрасывает ранее сохранённый ID аккаунта.
- `meta.xml` приведён к форме `<root>` по формату примеров сообщества.
- Сборщик контролирует все скомпилированные модули Python 2.7 и умеет проверять готовый ZIP через `--verify`.
- Добавлена анонимизированная диагностика `python.log` через `tools/diagnose_log.py`.
- Добавлены 12 регрессионных тестов, всего **60**.
- Реальную совместимость с клиентом и компиляцию Python 2.7 ещё необходимо подтвердить.


## 0.3.0 — 18 ноября 2026 (предварительная версия для разработчиков)

### Новое

- Добавлен модуль `analytics.py`: детерминированная сортировка и фильтрация истории по танку, аккаунту и датам; проверка ISO-дат.
- Сравнение **двух непересекающихся полных периодов** по 10, 30 или 100 боёв: средний урон и процент побед с дельтой в процентных пунктах.
- Скользящий средний урон с порогом 70% известных результатов в окне; отсутствующие данные не подменяются нулями.
- Таблица техники с числом боёв, процентом побед, средним уроном и полнотой измерений.
- CSV-экспорт с текущими фильтрами, UTF-8 BOM для Excel и защитой текстовых полей от интерпретации как формул.
- Фильтр по аккаунту, более информативная веб-панель и настройка размера окна сравнения.
- Базовая защита localhost HTTP-страницы: проверка `Host`, заголовки `no-store`, `nosniff`, CSP и запрет фреймов.
- 13 новых тестов; всего **48 автоматических тестов** на синтетических данных и имитации игрового клиента.
- Обновлена русскоязычная документация, подготовлены материалы для GitHub.

### Ограничения

- Реальный клиент Lesta не тестировался, игровой адаптер по-прежнему экспериментальный.
- Встроенного Gameface/React-окна пока нет: графики отображаются в браузере на `localhost`.
- `.mtmod` не создавался без отдельного интерпретатора Python 2.7 и не включён в релиз.
- Не подтверждены API игровых событий и отложенного кэша результатов.
